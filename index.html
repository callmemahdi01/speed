About measurement accuracy

We prefer position.coords.speed because the phone's GPS receiver uses satellite Doppler data and extra motion information to compute instantaneous speed, which is usually more accurate than calculating the distance between two consecutive points.

If that value is unavailable, the Haversine formula and the real time difference between two fixes are used as a fallback.

Actual accuracy depends on the phone's GNSS hardware, satellite reception quality, multipath effects, permissions, and browser implementation; this page cannot produce accuracy beyond what the phone hardware provides.
